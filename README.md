# 编码解码工具箱

> 分类：密码学与编码 ｜ 编号：项目 3 / 67 / 300 ｜ 生成日期：2026-10-06

## 简介
Base64 / URL / 十六进制 / 时间戳 / IP 混淆格式互转，排查乱码与编码痕迹。

## 功能清单
- Base64 编解码
- URL 编解码
- 十六进制转换
- 时间戳转换
- IP 格式转换器

## 使用方法
1. 直接用浏览器（Chrome / Edge）双击打开 `index.html`，无需安装任何东西。
2. 所有计算均在本地浏览器完成，断网也能用，数据不会上传到任何地方。
